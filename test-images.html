📝 What to do if images don't load:

  1. Check file names match exactly (lowercase, with hyphens)
  2. Check file extensions are .jpg or .png (not .jpeg, .JPG, .PNG)
  3. Check files are in correct folders:
    • Logo: images/logo.png
    • Services: images/services/[filename].jpg
  4. Clear browser cache (Ctrl+Shift+R or Cmd+Shift+R)
  5. Check console for errors (F12 → Console tab)

Quick Fix Commands:

# Check what files you have
ls -la images/
ls -la images/services/

# Run the image checker
./check-images.sh

# If you need to rename files (example):
# mv images/services/Sound-Temple.jpg images/services/sound-temple.jpg
